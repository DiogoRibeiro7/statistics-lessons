# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/).
We expect everyone to be respectful, inclusive, and considerate in all interactions.
Harassment and other inappropriate behavior are not tolerated. If you witness or
experience any misconduct, please contact the maintainers at
[dfr@esmad.ipp.pt](mailto:dfr@esmad.ipp.pt).
