# Contributing

Thank you for considering contributing to this project! Fork the repository and
create a feature branch for your changes. Ensure that your code is documented
with Google-style docstrings and includes inline comments.

When you open a pull request, link any relevant issues and describe the changes
clearly. Please review the [Code of Conduct](CODE_OF_CONDUCT.md) before
contributing.

## Running tests

Install the package with all dependencies using either `poetry install` or
`pip install -e .` before running the test suite:

```bash
poetry install  # or pip install -e .
pytest -q
```
