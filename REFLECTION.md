# Lessons Learned

The real-world projects highlighted the importance of working with well-known datasets to demonstrate statistical techniques end-to-end. Through the Iris and Breast Cancer case studies, we reviewed data loading, preprocessing, model selection, and evaluation. Implementing cross-validation and comparing models reinforced best practices for reproducibility and benchmarking.

Text analytics offered another perspective on machine learning pipelines. Using a subset of the 20 Newsgroups corpus for simple sentiment scoring showcased tokenization, TF‑IDF vectorization, and logistic regression on real text data.
Dimensionality reduction with PCA provided insight into how complex datasets can be summarized. Running PCA on the Wine dataset demonstrated how explained variance helps decide the number of components to retain.
Clustering the Iris dataset reinforced unsupervised methods by revealing natural groupings in the data.

Prescriptive analytics tied everything together by transforming model insights into actionable decisions. A small production planning problem demonstrated how linear programming can optimize resource allocation and maximize profit.
